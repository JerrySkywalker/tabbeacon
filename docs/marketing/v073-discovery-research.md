# v0.7.3 GitHub discovery surface research

Date: 2026-09-01

This record binds the v0.7.3 public-surface changes to the truthful product
boundary: TabBeacon is Codex-led, and "and more" is acquisition copy rather
than a blanket provider-support claim.

## Repository description

The prior GitHub description was:

> Live identity and status beacons for coding-agent tabs in Windows Terminal.

The applied v0.7.3 description is compact, within GitHub's repository
description limit, and says what a visitor receives without claiming generic
provider compatibility:

> Live status for Codex and more in Windows Terminal — no launcher required.

## Topics

The selected eight topics are intentionally a small, accurate set:

| Topic | Relevance |
| --- | --- |
| `coding-agents` | Identifies the intended coding-agent workflow category. |
| `codex-cli` | Identifies the primary production-supported coding-agent CLI. |
| `ai-coding` | Helps users find AI-assisted development tools without a provider-support claim. |
| `windows-terminal` | Names the required terminal surface. |
| `terminal` | Identifies the broader terminal presentation domain. |
| `cli` | Identifies the command-line distribution and workflow. |
| `rust` | Identifies the implementation and crates.io ecosystem. |
| `windows` | Identifies the current operating-system scope. |

No topic asserts Claude Code or OpenCode support. The production matrix remains:

- Codex CLI: production, capability-based;
- Agy CLI: production, exact admitted 1.1.19 profile;
- Claude Code: deferred;
- OpenCode: deferred.

## Social-preview upload boundary

The GitHub repository metadata API can update the description and topics, but
the social preview has no supported repository-content write endpoint. The
deterministic 1280x640 SVG and PNG are therefore committed for Owner upload in
the GitHub Settings UI. No browser session, cookie, or Settings UI automation
is used.
