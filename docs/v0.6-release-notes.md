# TabBeacon 0.6.0 release notes

TabBeacon 0.6.0 adds the first real second provider while preserving literal
agent commands and the provider-neutral core.

## Highlights

- Exact Agy 1.1.19 support through its official user-global structured title
  callback.
- Content-minimal Ready/Working projection, stable Root Workspace Anchoring,
  provider-aware Sessions, Integrations, and Why this title?.
- Compact provider badges with `auto`, `always`, and `off` policy.
- Ownership-safe Agy setup, migration, drift refusal, and uninstall.
- Codex and Agy session/root/config namespaces remain isolated while sharing
  the same workspace alias registry.

## Daily workflows

Codex-only:

```powershell
tabbeacon setup codex
codex
```

Agy-only:

```powershell
tabbeacon setup agy
agy
```

Both providers can run concurrently in stock Windows Terminal. TabBeacon adds
no launcher, agent wrapper, PATH shadow, PTY host, or global daemon.

## Capability boundary

Codex retains its admitted Hook-backed lifecycle and Windows Terminal
presentation. Agy contributes only the facts proven from Agy 1.1.19: stable
conversation identity, equal current/project workspace root, Ready from
`idle`, Working from `initializing`/`working`, and plain title output. Agy tab
color, WT progress, animation, approval, result-ready, stop authority, health,
and background-task count are not claimed.

See [Agy setup](agy-setup.md) and the [upgrade guide](v0.6-upgrade.md).
