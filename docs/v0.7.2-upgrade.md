# Upgrade from v0.7.1 to v0.7.2

v0.7.2 is a Codex subagent Hook stability hotfix. It preserves the provider and
presentation feature set while hardening root/subagent isolation, Stop-derived
ResultReady lifetime, exact legacy MCP Hybrid migration, and temporary
qualification-window cleanup.

Before replacing an in-use Windows binary, inspect bounded owned-worker state:

```powershell
tabbeacon upgrade-preflight
```

If preflight reports ambiguous processes, preserve them. Ambiguity does not
prove ownership; never kill coding-agent or Windows Terminal processes by image
name. Drain only when the preflight positively proves exact TabBeacon
ownership.

v0.7.2 is publicly available. After preflight admits replacement, use the same
channel used for installation:

```powershell
cargo install tabbeacon --version 0.7.2 --locked --force
```

Alternatively, replace the Windows x64 binary with the verified v0.7.2 GitHub
Release ZIP after checking its SHA-256 sidecar.

For an exact TabBeacon-owned historical Codex MCP Hybrid installation, run the
normal reviewed setup flow to converge to command-v1 Hooks. The transaction
preserves unrelated Hooks, MCP servers, and configuration. If managed Hook
definitions change, open Codex `/hooks` and manually review the exact isolated
definitions; do not use a trust-bypass mechanism.

The package upgrade itself does not mutate an Owner's production Codex
configuration or Hook trust. Daily commands remain literal `codex` and `agy`.
