# Upgrade from v0.7.2 to v0.7.3

v0.7.3 changes discovery, demo, README, and package presentation only. It does
not change runtime/provider behavior, configuration ownership, Hook trust, or
the literal daily `codex` and `agy` commands.

Before replacing an in-use Windows binary, inspect bounded owned-worker state:

```powershell
tabbeacon upgrade-preflight
```

If preflight reports ambiguous processes, preserve them. Ambiguity does not
prove ownership; never kill coding-agent or Windows Terminal processes by image
name. Drain only when preflight positively proves exact TabBeacon ownership.

After v0.7.3 is publicly released and preflight admits replacement, use the
same channel used for installation:

```powershell
cargo install tabbeacon --version 0.7.3 --locked --force
```

Alternatively, replace the Windows x64 binary with the verified v0.7.3 GitHub
Release ZIP after checking its SHA-256 sidecar.

No setup rerun is required for this presentation-only maintenance release.
If setup is intentionally reviewed again, unrelated Hooks, MCP servers,
provider configuration, and manual trust state retain their existing ownership
boundaries.

Until the separate public release transaction is explicitly authorized and
verified, v0.7.2 remains the current public release and the v0.7.3 commands and
assets above are release-candidate instructions rather than public-availability
claims.
