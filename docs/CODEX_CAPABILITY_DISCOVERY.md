# Codex Local Capability Discovery

TabBeacon runs discovery locally, bounded, noninteractive, and without a
network or Codex login requirement.

1. Run `codex features list` and read the content-minimal `hooks` feature
   status. An enabled status proves the required capability; an explicit false
   or missing status is incompatible; failure to parse or run is unproven.
2. Run `codex app-server generate-json-schema --out <temporary directory>`.
   The bundle is generated by the installed binary and is version-matched
   evidence, but is optional for Hook operation. TabBeacon stores only a
   SHA-256 fingerprint, then removes the temporary bundle.
3. Use the bounded command-Hook V1 structural contract as the conservative
   runtime and setup fallback. A manifest-proven existing MCP transport stays
   in place rather than being guessed from a version string.

## Cache

The cache lives below TabBeacon's Codex integration state root. It contains
only a schema identifier, the SHA-256 identity of the resolved Codex
executable, a capability fingerprint, the compatibility state, and the
selected bounded contract. It contains no schema body, configuration, Hook
payload, prompt, conversation, token, or credential.

The executable digest and capability fingerprint are the cache key material.
Changing the executable invalidates the cache and re-runs discovery. Read-only
doctor may reuse cache but never writes it; ownership-authorized mutation can
persist it after a successful local preflight.

## Observed local evidence

On 2026-08-25, the installed `codex-cli 0.149.0` reported `hooks stable true`.
Its offline `app-server generate-json-schema` invocation completed and emitted
an app-server schema bundle, but that bundle contained no TabBeacon Hook
declaration surface. Therefore the production fallback remains the command
contract; schema generation is not an App Server runtime dependency.

The upstream `openai/codex` source inspected at
`70b5cfc73b25458a7af225d24b16ef4794f8f380` documents that
`generate-json-schema` produces artifacts matched to the exact binary version.
