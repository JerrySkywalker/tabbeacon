# TabBeacon v0.7.1 maintenance closeout

v0.7.1 is a maintenance and closeout release. It improves public brand and
current-truth quality without changing TabBeacon runtime behavior.

## Maintained public identity

- Repaired the horizontal TabBeacon SVG wordmark with a deterministic local
  glyph grid. Glyphs use a shared cap height and baseline, bounded cells,
  explicit advances and gaps, and zero overlap.
- Preserved the existing TabBeacon mark, monochrome mark, and state strip.

## Current product truth

- Reconciled current-facing Agy and architecture text with the exact admitted
  Agy 1.1.19 production profile while retaining historical qualification and
  release records as history.
- Corrected the governance roadmap's current public-release pointer.
- Kept Codex CLI and Agy CLI 1.1.19 as the only production-supported coding
  agents. Claude Code and OpenCode remain deferred.

## Deliberate dogfood pause

After v0.7.1, active feature development is paused for an Owner dogfood/use
period. The v0.8 option set is non-authoritative; no v0.8 roadmap or feature
implementation is created by this release.

## Unchanged boundaries

```text
RUNTIME_BEHAVIOR_CHANGED=false
PROVIDER_BEHAVIOR_CHANGED=false
NATIVE_TAB_ICON_DISPOSITION=NO_GO
```

The release adds no provider, Codex App Server backend, native-tab-icon route,
XAML Diagnostics work, launcher, PATH shadow, PTY host, daemon, timeout tuning,
worker behavior, HookStat integration, or new presentation semantics.
