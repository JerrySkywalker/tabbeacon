# Upgrade from v0.6.0 to v0.6.1

This guide describes the current public v0.6.1 release.

Upgrade through the same channel used for installation:

```powershell
cargo install tabbeacon --version 0.6.1 --locked --force
```

or replace the Windows x64 binary with the verified v0.6.1 release asset.

Before replacing an in-use Windows binary, inspect bounded owned-worker state:

```powershell
tabbeacon upgrade-preflight
```

Then reconcile only TabBeacon's exact owned Codex declarations:

```powershell
tabbeacon setup codex
```

Setup preserves unrelated Codex configuration and third-party Hook entries.
Codex capability discovery is local and capability-based; the observed version
does not grant mutation authority. If TabBeacon changes an exact owned Hook
declaration, review it manually in Codex `/hooks`. Setup never grants trust
automatically.

Existing presentation settings, workspace aliases, and provider configuration
remain in their owned stores. Daily use remains literal `codex`. v0.6.1 adds
no native tab-icon backend, XAML integration, terminal injection, global async
Hook conversion, or promise that PowerShell always starts within one second on
an overloaded host.
