# Upgrade from v0.6.1 to v0.7.0

After the v0.7.0 public release is available, upgrade through the same channel
used for installation:

```powershell
cargo install tabbeacon --version 0.7.0 --locked --force
```

Alternatively, replace the Windows x64 binary with the verified v0.7.0 GitHub
Release asset and its SHA-256 sidecar.

Before replacing an in-use Windows binary, inspect bounded owned-worker state:

```powershell
tabbeacon upgrade-preflight
```

If the preflight reports ambiguous processes, preserve them: ambiguity does not
prove ownership. Use read-only diagnosis, let relevant sessions exit naturally,
and use an exact owned drain only when the current preflight proves ownership.
Do not kill coding-agent processes by image name.

Reconcile only TabBeacon's exact owned provider declarations after replacing
the binary:

```powershell
tabbeacon setup codex
```

For the admitted Agy 1.1.19 profile, the matching supported setup remains:

```powershell
tabbeacon setup agy
```

Existing presentation settings, workspace aliases, supported provider
configuration, unrelated Hooks, and manual Hook-trust boundaries remain
separate from this documentation-focused release. Daily commands remain
literal `codex` and `agy`.

v0.7.0 does not add Native Windows Terminal tab icons, XAML Diagnostics,
terminal instrumentation, a launcher, a PATH shadow, a PTY host, or a global
daemon. `TitleMarkBackend` remains the production presentation path.
