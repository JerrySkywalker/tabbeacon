# Upgrade from v0.7.0 to v0.7.1

v0.7.1 is a maintenance-only release. It does not change provider semantics,
Hook trust, user configuration ownership, worker behavior, or terminal
presentation behavior.

Before replacing an in-use Windows binary, inspect bounded owned-worker state:

```powershell
tabbeacon upgrade-preflight
```

If the preflight reports ambiguous processes, preserve them. Ambiguity does not
prove ownership; do not kill coding-agent processes by image name. Use an exact
owned drain only when the current preflight proves ownership.

After v0.7.1 is publicly available and the preflight admits replacement, use
the same channel used for installation:

```powershell
cargo install tabbeacon --version 0.7.1 --locked --force
```

Alternatively, replace the Windows x64 binary with the verified v0.7.1 GitHub
Release asset and its SHA-256 sidecar.

Existing presentation settings, workspace aliases, supported provider
configuration, unrelated Hooks, and manual Hook-trust boundaries remain
separate from this maintenance release. Reconcile a provider only through its
normal ownership-safe setup flow when a diagnostic or a reviewed change calls
for it; do not use an upgrade as a trust bypass. Daily commands remain literal
`codex` and `agy`.
