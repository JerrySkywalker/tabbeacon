# Upgrade from v0.5.2 to v0.6.0

Upgrade the package through the same channel used for installation:

```powershell
cargo install tabbeacon --version 0.6.0 --locked --force
```

or replace the Windows x64 binary with the verified v0.6.0 release asset.

Existing Codex configuration, manual Hook trust, presentation settings,
workspace aliases, and portable preferences remain owned by their existing
stores. Run the normal provider setup after replacing the binary so its exact
owned executable reference is current:

```powershell
tabbeacon setup codex
```

To add Agy 1.1.19, run:

```powershell
tabbeacon setup agy
```

Older TabBeacon Agy qualification scaffolding did not admit a production
provider. If an exact TabBeacon-owned early title declaration exists, v0.6.0
verifies its original backup, callback, applied document, and executable before
migrating it to the persistent supported declaration. Foreign title owners or
drift are never overwritten.

Daily commands remain literal `codex` and `agy`. Agy versions other than
1.1.19 are read-only diagnostics and do not inherit support by version order.

Before replacing an in-use Windows binary, use:

```powershell
tabbeacon upgrade-preflight
```

This reports bounded owned-worker state without terminating unrelated
processes.
