# TabBeacon v0.7.0 release notes

## Open-source experience

v0.7.0 gives TabBeacon a clearer public home without changing the literal
coding-agent commands that users run every day.

- An original TabBeacon SVG identity, including a compact mark, horizontal
  logo, monochrome mark, and semantic state strip.
- An English-canonical README and a full Simplified Chinese counterpart, with
  exactly two project-health badges: Rust/MSRV and Windows CI.
- A separate Supported Coding Agents table and a scalable compatibility guide.
- A privacy-safe real Windows Terminal screenshot rendered by TabBeacon's
  deterministic presentation fixture. It is not presented as a live model
  conversation.
- A documentation portal with getting-started, configuration,
  troubleshooting, FAQ, design, build/test, and release-process guides.
- CONTRIBUTING v2 and an offline documentation contract check in Windows CI.

## Supported coding agents

Codex CLI remains production-supported with literal daily command `codex` and
capability-based compatibility. Agy CLI remains production-supported only for
the exact admitted Agy 1.1.19 profile, with literal daily command `agy`.

Claude Code and OpenCode remain deferred. v0.7.0 adds no third provider and no
Codex App Server backend.

## Native Windows Terminal tab icon research

```text
NATIVE_TAB_ICON_DISPOSITION=NO_GO
PRODUCTION_RUNTIME_NATIVE_ICON=false
```

Stock Windows Terminal still has no supported public application-controlled
native-tab-icon bridge. The remaining documented XAML Diagnostics route is
process instrumentation, and it could not meet the admitted isolated-target
safety bar on the qualified host. No XAML attachment, visual-tree enumeration,
`IconSource` mutation, snapshot, or restore was attempted.

`TitleMarkBackend` remains TabBeacon's production visual path. Native tab
icons do not ship in v0.7.0 and this conclusion does not promise a future
integration.

For the detailed evidence, see the [research disposition](research/WT_NATIVE_ICON_DISPOSITION.md)
and [ADR 0018](adr/0018-native-tab-icon-feasibility-no-go.md).
