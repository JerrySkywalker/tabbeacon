# TabBeacon v0.8.0 release notes

v0.8.0 adds independent presentation preferences for Codex, Agy and Cursor, strict color-only Cursor integration, supported structured Codex state, and an [English/Chinese terminology guide](terminology.md). Normal launch commands remain `codex`, `agy` and `agent`.

## Provider scope

- Codex admission is capability-based. The observed 0.159.0 command-Hook baseline has 11 events. Real Interrupt/recovery evidence belongs to a separately pinned 0.157.1 profile and is not generalized to 0.159.0.
- Agy title support admits **exactly 1.1.19 and 1.2.7**. Official signed 1.2.7 showed a real Working title in a mixed Codex/Cursor/Agy session. It has no TabBeacon tab color, progress, animation, health or result-ready capability. The real Ready/idle visible transition remains **UNPROVEN**: after the observed response the title still read `Agy⭕AGYWORKS`. Isolated tests map an actual `idle` callback to Ready; response text is not used to infer it. Daily 1.2.13 is **not admitted**.
- Cursor uses exact-owned project Hooks for strict color-only or preserve-native operation while Cursor keeps its native title. The mixed real session showed independent working/completion colors without cross-tab interference. The earlier dual-Cursor observation is separately scoped.

The Owner stopped further attended same-tab sequential handoff and Agy preserve-native-to-title-only switching. Both real L4 scenarios were **not executed**. Existing deterministic, isolated configuration, owned UIA and restore proofs retain only their recorded scopes.

## Known limitation

In the audited Codex **0.157.1 original-command Hook path**, Warning, Failed and the original HTTP 404 class lack authoritative structured signals. Those errors may leave tab state unchanged. Detection is **not PASS** and [Issue #116](https://github.com/JerrySkywalker/tabbeacon/issues/116) remains **OPEN**. TabBeacon does not infer errors from terminal text, ANSI, transcripts or model output.

## Installation

Install the official [crates.io package](https://crates.io/crates/tabbeacon) with `cargo install tabbeacon --version 0.8.0 --locked`. For an existing managed Codex installation, follow the [v0.8.0 upgrade guide](v0.8.0-upgrade.md) for ownership-aware reconciliation and normal Hook trust review. The Windows ZIP and SHA-256 sidecar are attached to the [v0.8.0 GitHub Release](https://github.com/JerrySkywalker/tabbeacon/releases/tag/v0.8.0).
